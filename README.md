# filipsjostrand.github.io

The website is a 
- planning application. <br>
- portfolio website (about me). <br>

It is programmed in JavaScript (with HTML & CSS).
<br><br>

## Application Headers (Description) 
- Todos (Todos)
- Vecka (Week)
- Plan (Plan)
- Timer (Timer)
- Om (About)
<br><br>


![Todos (Todos)](media/img/Todos.jpg "Todos")

Add 1-3 Todos.
<br><br>

![Vecka (Week)](media/img/vecka-img.jpeg "Vecka")

View the current week plan.
<br><br>

![Plan (Plan)](media/img/plan-img.jpeg "Plan")

Make plans (add/edit/remove)
- Save plan
- Load plan
- Tasks can be ordered (if they start with a time [format: hh:mm])
<br>

![Timer (Timer)](media/img/timer-img.jpeg "Timer")

Start a count-up or countdown timer
- Start up-beat/slow music
<br>

![Om (About)](media/img/om-img.jpeg "Om")

Presentation about me
- Work Experience
- Education
